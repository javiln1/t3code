# Response notifications

T3 Code can send a system notification when an agent finishes a response while the app is in the background.

Open **Settings → General** and enable **Response notifications**. Your browser or operating system will ask for notification permission the first time you enable it.

Notifications are sent only when T3 Code is hidden or unfocused. Clicking one returns to the completed thread. The setting applies to the current browser or desktop installation and covers threads from every connected environment.

If notifications do not appear, confirm that notifications are allowed for T3 Code in your browser and operating-system settings.
